# Abolfazl Yazdi — Personal Website

سایت: https://abolfazlyazdi.github.io/resume/

## ویرایش رزومه
1. فقط `assets/js/data.js` را ویرایش کن.
2. بعد اجرا کن: `node build.js`
   این دستور محتوا و JSON-LD را داخل `index.html` و `en/index.html` می‌نویسد تا موتورهای جست‌وجو بدون اجرای JavaScript هم آن را ببینند.
3. commit و push کن.

## فایل‌های مهم
- `assets/images/profile.jpg` — عکس پروفایل (۱۰۰۰×۱۰۰۰)
- `assets/images/og-image.jpg` — تصویر پیش‌نمایش لینک (۱۲۰۰×۶۳۰)
- `assets/resume-abolfazl-yazdi-{fa,en}.pdf` — رزومه‌ی PDF

## SEO
- در Google Search Console سایت را ثبت و `https://abolfazlyazdi.github.io/resume/sitemap.xml` را ارسال کن.
- `robots.txt` فقط در ریشه‌ی دامنه خوانده می‌شود. برای اثر واقعی، ریپو را `abolfazlyazdi.github.io` نام‌گذاری کن یا دامنه‌ی اختصاصی وصل کن.
